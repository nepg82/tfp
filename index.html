GitHub Data Repository

The application can be public; this repository should be private.

A GitHub token is effectively a password. Give it access only to the private data repository and Contents: Read and write.

Encryption

Your ledger is encrypted in the browser before it is uploaded. The encryption password is never sent to GitHub.

If you forget this password, an encrypted GitHub backup cannot be decrypted.

Local Data

Local IndexedDB remains the working copy. GitHub sync is an additional backup and multi-device store.
